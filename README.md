# Roast Your Fridge — One Line, One Laugh

A single-line roast of my fridge, written by a small Python 3.13 program
(standard library only, no network) for the make.fun competition
`u-suzy-one-line-one-laugh-roast-your-fridge-f1063521`.

The entry: *"My fridge hums at 3 a.m., gossiping about me to the milk."*

## How to run

```sh
python3 main.py
```

This writes the one-line entry to `/output/entry.txt` (UTF-8, 57 characters,
a single line). The program asserts the gate before writing: exactly one
line, 1–200 characters, non-empty — and re-reads the file to verify it.
